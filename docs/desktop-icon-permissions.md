# 桌面圖示權限

科技球或系統匣右鍵：「桌面整理工具 → 桌面圖示權限」。

## 開機不再要求管理員權限

開機及桌面變更時的自動同步不會開啟 Windows 管理員確認。遇到受權限保護的捷徑時，整理視窗只顯示提示，請改用下列任一次性設定；完成後開機不需再確認：

- 安裝背景輔助程序（安裝程式預設建議安裝，或從選單「安裝／修復背景輔助程序」）。
- 一次授權已收納的捷徑。

背景輔助程序已啟用時，即使個別項目仍無法變更（例如有明確拒絕規則），也不會改用管理員確認重試。

## 安裝位置

小助手安裝於 `C:\Program Files\METech-desktop-assistant`（所有使用者），安裝目錄不可變更。只有管理員能修改此目錄，因此以管理員權限執行的 PowerShell 程序無法被一般程式替換。安裝程式會自動移除舊的個人安裝版本（`%LOCALAPPDATA%\Programs`），保留設定與背景輔助程序。

安裝及每次自動更新需要一次 Windows 管理員確認；若更新時拒絕確認，小助手會自動以原版本重新開啟。若小助手從一般帳號可寫入的位置執行（例如開發用目錄或尚未移轉的舊版），需要管理員權限的設定會被拒絕並顯示原因。

## 指定捷徑授權

「一次授權已收納的捷徑」需要一次 Windows 管理員確認，只為目前整理視窗內的桌面 `.lnk`／`.url` 捷徑，授予目前帳號 WriteAttributes 權限。原位置、捷徑內容、指向目標與其他權限維持原狀。一般檔案、資料夾與捷徑目標不會獲得新增權限。

這個權限適用於同一帳號的所有程式；它允許修改該捷徑的屬性。捷徑重建後可能需要重新授權。已有明確拒絕規則的項目會保留原權限，並顯示原因。

「還原捷徑原本權限」需要管理員確認，依受保護的備份還原。若捷徑已被替換，或其他程式改過權限，會保留現有項目，避免覆蓋其他修改。

## 背景輔助程序

安裝程式提供可選的背景程序；也可以選「安裝／修復背景輔助程序」。首次需要管理員確認；之後勾選「使用背景輔助程序」，隱藏及還原圖示時由已授權的排程工作處理，小助手繼續以一般權限執行。

排程工作以 SYSTEM 身分執行，因此屬於較高權限元件。它只接受經驗證的目前使用者程序，僅處理個人及公用桌面項目的 Hidden／System 屬性，拒絕重新導向連結與多重硬連結；不接受執行程式或任意命令的要求。

同帳號的其他程式也能啟動這個工作，並要求處理桌面項目的屬性。使用者身分核對只能隔離其他帳號，無法識別同帳號內的惡意程式。公用桌面項目的屬性變更也會影響其他使用者。

程式、設定與復原記錄放在受管理員保護的 Program Files 目錄。一般帳號只有讀取及啟動指定工作所需的權限；程式結束、移除項目或輔助程序退出時，還原其新增的隱藏屬性。

背景程序目前支援個人桌面、AppData、Local AppData 均位於標準使用者個人資料夾內的配置。重新導向連結桌面及不符此配置的系統，會顯示原因並保留一般模式。

取消勾選可停用背景模式。「移除背景輔助程序」移除排程工作；指定捷徑授權仍可另外還原。一般自動更新會保留已有設定，更新／修復受保護程式仍需管理員授權。UAC 保持開啟。

這兩種方式均會擴大原有權限範圍。範圍限制與防護測試能降低風險，不能保證沒有資安風險。

## 目前驗證狀態

一般模式的原生檔案測試、118 項單元測試及背景工作程式的路徑範圍測試通過。範圍測試以一般權限在專用測試資料夾執行，涵蓋桌面外／子資料夾項目、多重硬連結、重新導向連結、路徑替換、首次匯入復原記錄及退出復原。

維護用啟動參數 `--no-icon-elevation` 可在單次執行中使用一般圖示權限，不啟動高權限圖示工作或自動提出圖示 UAC 要求；受保護項目仍會顯示錯誤。選單中的明確管理員設定操作仍需 UAC。

完整 SYSTEM 排程執行、工作與 Program Files 檔案的權限拒絕，以及一次授權／還原流程仍需完成管理員整合測試。2026-10-05 修正版維持 Ver.1.7.0 並更新自動更新管道；靜默更新保留既有設定，不會自行新增背景程序或捷徑授權。現有發布版未使用 Authenticode 程式碼簽章；範圍測試不能代替程式簽章或獨立安全稽核。

已修正 Windows PowerShell 5.1 在再次寫入受保護檔案時，將空備份路徑轉成空字串而造成的 File.Replace 路徑格式錯誤。使用 `npm run test:desktop-icon-permissions:native` 驗證中文及含空白的路徑、連續替換與原權限保留，並核對捷徑身分、路徑鎖定及硬連結拒絕。
