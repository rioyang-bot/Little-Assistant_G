# 整理視窗沒有顯示時的處理方式

## 原始 Ver.1.7.0

1. 在科技球或系統匣小助手圖示的右鍵選單，選擇「桌面整理工具 → 顯示所有整理視窗」。
2. 如果仍然空白，從系統匣選單選擇「結束小助手」，等待程式結束後再重新開啟。

請保留原有整理視窗與設定檔。視窗空白不代表檔案被刪除；這次實際案例的 17 個項目仍在原位置，重新開啟後背景和內容均恢復。

## Ver.1.7.0 同版修正版的復原功能

原始 Ver.1.7.0 不會偵測同版本更新，需先下載同版修正版覆蓋安裝一次。

科技球或系統匣右鍵選單：「桌面整理工具 → 復原整理視窗 → 選擇視窗名稱」。

這個動作重新建立選定的視窗，並置於滑鼠所在螢幕的中央。原檔案路徑、項目排列、背景、顏色、透明度及鎖定設定都會保留；其他整理視窗不會改變。若該視窗正在開啟設定，未儲存的預覽會取消。請先完成檔案拖曳，再執行復原。

## 本次確認與驗證

- 實際問題是「檔案文件」的頁面和項目已載入，但透明視窗的畫面空白；單純移到前面仍然空白。視窗重新開啟後恢復顯示。尚未確認造成原生畫面空白的底層原因。
- 重建測試確認新的視窗能顯示內容、位置在可用螢幕內，並保留設定與檔案內容。
- 連續點擊會合併為同一次復原；舊視窗事件不會移除新視窗的狀態。
- 復原包含開啟中的設定視窗時，會完整解除設定視窗與底層排序的生命週期。
